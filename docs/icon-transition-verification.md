## 3. 代码审查

| 检查项 | 结果 |
| --- | --- |
| 快速连续变化合并 | `StatusItemController`：过渡中到达的新状态只置 `hasQueuedUpdate`，不打断当前动画；结束后从刚落地状态用最新目标再算一次（single-flight + latest-wins，不排队积压） |
| 首帧 / 外观切换不播过渡 | `hasRenderedOnce` / `appearanceKey` 变化 → `snapTo` 直接落静态帧 |
| 降级路径 | `transitionEnabled` = 设置项 + Reduce Motion + 低电量 + `DSH_STATUS_DISABLE_TRANSITIONS`；`shouldAnimate` 同源控制彗星；`runAnimation` 关闭时过渡仍播、彗星静止 |
| 过渡期间静态兜底 | `button.image` = 透明占位图；完成回调里移除临时层、换回完整静态帧、同步彗星（不重启旋转）；generation token 防过期回调 |
| CA 隐式动画覆盖显式动画 | 已修复：终值写入走 `setModel(...)`（`CATransaction.setDisableActions`）；踩坑现象为彗星淡出从 0.18s 变瞬间消失 |
| 彗星旋转不重启 | 签名只含 radius/width/color/dark/animate，状态数量变化不重启 |
| 临时层清理 | 过渡结束 `transitionLayers` 全移除（≤6 个临时层） |

## 4. 无法验证 / 残余风险

1. **真机手感**：本记录只能证明时序/几何符合规格，主观手感（是否「烦」、节奏是否合适）需用户验收。
2. **Reduce Motion / 低电量**：只做了代码路径审查，未在真机上逐项开关复测。
3. **过渡期间透明占位图**：若恰逢菜单栏整体重建（≤0.6s 窗口）可能见一帧空位；日常状态变化未观测到。
4. **连接抖动无防抖**：桥重启/网络闪断会各播一次断连/恢复；如实测明显再加 0.5–1.0s 防抖。
5. 环境因素：真机捕获期间系统菜单栏项（如系统指示器）出现会让所有状态项平移，固定区域分析会错位；
   脚本已切 Finder 并建议用时间线对齐，但仍属环境噪声。
