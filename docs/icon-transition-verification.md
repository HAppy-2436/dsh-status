## 2. 静态「视觉居中」修正（红环偏上）

现象：用户反馈「红色的那个环看起来偏上 1–2px」。8× 位图审计（新增 `--render-icon-states <dir>`，
输出 2×/8× 透明底 PNG）定位到根因：**中心数字垂直按墨迹 bbox 居中 + 阴影 offset 向下 0.3pt**，
导致环内「亮部（数字）偏上、暗部（阴影）偏下」，外环视觉上被推高。

| 指标（红环 + 数字 1，8× 位图） | 修复前 | 修复后 |
| --- | --- | --- |
| 环心 vs 画布中心 | (0, 0) | (−0.06, −0.06)pt |
| 数字墨迹**面积质心**相对环心（垂直） | **+0.42pt（上）** | +0.07pt |
| 阴影质心相对环心（垂直） | **−0.33pt（下）** | +0.16pt |
| 数字 2 / 3 / 8 墨迹面积质心（垂直） | +0.26 / −0.26 / — | +0.06 / +0.01 / −0.01pt |
| 数字 2 / 3 / 8 阴影质心（垂直） | — | +0.05 / −0.04 / −0.02pt |

修复：① 水平 + 垂直都按字形轮廓**面积质心**对齐画布中心；② 数字阴影改为**原地对称扩散**（offset 0）。
对照图：[`previews/icon-centering-before-after.png`](previews/icon-centering-before-after.png)。

复现：

```bash
app/.build/release/DSHStatusBar --render-icon-states /tmp/iconaudit
# 输出 attention-stopped-dark@8x.png 等；测量脚本思路：红像素拟合圆心得环心，
# 白色像素 alpha 加权质心得墨迹重心，黑色半透明像素（alpha<0.9 且 RGB<80）得阴影重心。
```

## 3. 代码审查

| 检查项 | 结果 |
| --- | --- |
| 快速连续变化合并 | `StatusItemController`：过渡中到达的新状态只置 `hasQueuedUpdate`，不打断当前动画；结束后从刚落地状态用最新目标再算一次（single-flight + latest-wins，不排队积压） |
| 首帧 / 外观切换不播过渡 | `hasRenderedOnce` / `appearanceKey` 变化 → `snapTo` 直接落静态帧 |
| 降级路径 | `transitionEnabled` = 设置项 + Reduce Motion + 低电量 + `DSH_STATUS_DISABLE_TRANSITIONS`；`shouldAnimate` 同源控制彗星；`runAnimation` 关闭时过渡仍播、彗星静止 |
| 过渡期间静态兜底 | `button.image` = 透明占位图；完成回调里移除临时层、换回完整静态帧、同步彗星（不重启旋转）；generation token 防过期回调 |
| CA 隐式动画覆盖显式动画 | 已修复：所有终值写入走 `setModel(...)`（`CATransaction.setDisableActions`）；踩坑现象为彗星淡出从 0.18s 变瞬间消失 |
| 彗星旋转不重启 | 签名只含 radius/width/color/dark/animate，状态数量变化不重启 |
| 临时层清理 | 过渡结束 `transitionLayers` 全移除（≤6 个临时层） |

## 4. 无法验证 / 残余风险

1. **真机手感**：最终版本安装后屏幕被锁定，无法再做一轮屏幕录制；用户解锁后看菜单栏即可确认红环是否仍偏、
   以及 M9（运行中→已完成）与断连淡化的观感。
2. **Reduce Motion / 低电量**：只做了代码路径审查，未在真机上逐项开关复测。
3. **过渡期间透明占位图**：若恰逢菜单栏整体重建（≤0.6s 窗口）可能见一帧空位；日常状态变化未观测到。
4. **连接抖动无防抖**：桥重启/网络闪断会各播一次断连/恢复；如实测明显再加 0.5–1.0s 防抖。
5. 环境因素：真机捕获期间系统菜单栏项（如系统指示器）出现会让所有状态项平移，固定区域分析会错位；
   脚本已切 Finder 并建议用时间线对齐，但仍属环境噪声。
