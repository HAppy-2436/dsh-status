## 0. 结论先行

1. **动效从「只有外环变化有过渡」扩展到全部语义迁移**：空闲 / 待办 / 运行中 / 双层 / 未连接之间的 18 类切换（§3）都有设计过的过渡，不再瞬切。
2. **保留已验收语言**：外环 0.45s `easeInOut` 自 12 点顺时针扫入；彗星旋转 6s/3 圈 ±32%、呼吸 0.26⇄0.58/1.7s 不变。
3. **一次切换 = 一拍**：所有通道共用一条时间线，单次总时长 **≤0.60s**；同轨交接（外环 r7.9 ↔ 彗星 r7.9）让退场方先走。
4. **方向即语义**：顺时针 = 出现/接管，逆时针 = 收回/让位；数字只做 ≤2.4pt 垂直「里程表」滚动（增加向上、减少向下），**永不做水平位移**。
5. **内容的目标位置绝不变化**：不做布局/尺寸/窗口动画，不整体位移、不缩放；只有数字字形在固定中心槽内滚动。
6. **只用 Core Animation 图层 + 位图交叉淡化**：不逐帧重绘、不新增 Timer/DisplayLink；过渡结束临时层数 = 0，稳态 CPU 0.0%（实测；前提是外观通知按深浅色去重 + 静态图缓存，见 §4.4）。
7. **降级三档**：`transitionAnimation` 关 / Reduce Motion / 低电量 → 过渡瞬时；`runAnimation` 关 → 彗星静止但状态过渡仍播。
8. **已知取舍**：过渡期间 `button.image` 是透明占位图（保证状态项宽度），画面全部由临时图层合成；结束后立刻换回完整静态图。极端情况下（≤0.6s 窗口内菜单栏整体重建）可能看到一帧空位，换来的是任何时刻静态兜底都是完整帧。
9. **不变原子不参与淡化**：内容通道只对「真的变了的内容原子」（鲸鱼 / 轨道 / 未连接符号）做交叉淡化；两端相同的原子（同色外环、未变数字）放在一张 **opacity 恒 1 的公共静态层**。旧实现无条件双图交叉淡化会让相同像素在 t=0.5 处叠成 75% 不透明度（环/数字轻闪），本轮已修（P1-2）。
10. **状态判定按「渲染文本」归一化**：`>99` 一律显示 `99+`，因此 100→101 这类推送**不播过渡**（旧实现按数值差滚动同一张「99+」，实测双影）。

## 1. 状态空间与视觉原子

### 1.1 状态枚举

连接态只有「已连接 / 未连接」两档；已连接下由「待办（需要介入）」与「运行中」两个维度组合：

| 状态 | 代号 | 鲸鱼 | 外环 | 轨道 | 彗星弧 | 中心数字 | 未连接符号 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 未连接 | `disconnected` | — | — | — | — | — | 虚线环 + 短横 |
| 完全空闲 | `idle` | ✓ | — | — | — | — | — |
| 只有待办 | `attention` | — | ✓（红/黄/绿） | — | — | ✓（按语义） | — |
| 只有运行中 | `running` | — | — | ✓ @ r7.9 | ✓ @ r7.9 | ✓（运行数） | — |
| 运行中 + 待办 | `both` | — | ✓（红/黄/绿） | ✓ @ r4.95 | ✓ @ r4.95 | —（双层不放数字） | — |

约束（不变）：外环单色、颜色取最高优先级 **红(已停止) > 黄(待回答) > 绿(已完成)**；双层时中心不放数字；
`connected == false` 时视觉以未连接符号为准。

### 1.2 视觉原子与动画介质

| 原子 | 内容 | 过渡介质 | 通道 |
| --- | --- | --- | --- |
| 鲸鱼 | 18.8pt 宽 glyph | 位图快照 opacity 交叉淡化 | 内容 |
| 外环 | r7.9 / 线宽 2.1 / 整圈单色 | `CAShapeLayer` 的 `strokeEnd` / `strokeColor`；换色 = 旧环静态层 + 新色层覆盖 | 外环 |
| 轨道 | 淡色整环（16%），半径随层级 7.9 或 4.95 | 位图快照 opacity 交叉淡化 | 内容 |
| 彗星弧 | 亮弧，半径 7.9 或 4.95 | 常驻 `CAShapeLayer`：opacity、`path` 半径插值、`transform.rotation.z`、既有呼吸 | 彗星 |
| 中心数字 | 1/2/3 字形，圆体 Bold；1–2 位面积质心居中、3 位（99+，6.4pt）ink bbox 居中 | 位图快照 opacity + `transform.translation.y` | 数字 |
| 未连接符号 | 虚线环 + 短横（一个符号，不拆开） | 位图快照 opacity 交叉淡化 | 内容 |

### 1.3 数字语义（不变，仅动画需要区分）

| 设置「中心数字」 | 显示值 | 0 的约定 |
| --- | --- | --- |
| 全部任务（默认） | 非空闲任务总数 | 0 = **不显示数字**，绝不渲染 "0" |
| 需要介入 | 待回答+已停止+已完成；为 0 时回落为运行数 | 同上 |
| 与环色一致 | 环色对应状态计数；无待办时回落为运行数 | 同上 |
| 不显示 | 永远 nil | — |

- 数字格式：`count > 99` 显示 `99+`；字号 10.4 / 9.0 / 6.4pt 随字形数递减。
  1–2 位数字按**字形轮廓面积质心**水平居中（视觉居中）；3 位（仅 `99+`）按 **ink bbox** 居中、6.4pt，
  左右各留 ≥0.4pt 余量、不压外环内缘（2026-11-08 验收发现旧 7.6pt + 质心居中会越界 1.9pt，已修）。
- 过渡只改变「显示方式」，不改变上述取值规则。

## 2. 统一动效语言

### 2.1 三条不可违反的原则

1. **不位移**：图标内容（环心、数字锚框、鲸鱼 bbox 中心）在过渡中的目标位置恒定；禁止整体平移/缩放/布局动画/窗口动画。
   —— 直接回应用户对「内容一会下一会上」的批评：两段式位移一律违规。
2. **单拍**：一次状态迁移 = 一拍；所有通道共用同一时间线（§2.4），不各动各的。
3. **语义→运动隐喻**：每个动画都能用一句话解释「它在表达什么」（§2.3），解释不了就不做。

### 2.2 时长层级（对应 `IconMotion`）

| 层级 | 参数 | 缓动 | 用途 |
| --- | --- | --- | --- |
| 主拍 | **0.45s**（同轨让位变体 0.40–0.42s） | `easeInOut` | 外环扫入/收回/换色、彗星半径迁移 |
| 内容交叉 | **0.24s** | `easeInOut` | 鲸鱼、轨道、未连接符号、断连整体淡化 |
| 彗星进出 | **0.18s** | `easeInOut` | 彗星弧淡入/淡出 |
| 数字滚动 | **0.18s**（新值延迟 **0.05s**，仅「有方向」的增减） | `easeOut` | 同字形数增减 |
| 数字出现/消失、字形数变化 | **0.18s**（不加错峰） | `easeInOut` | M15/M18 |
| 复合上限 | **≤0.60s** | — | 一次迁移总时长硬上限 |
| 错峰阶梯 | `0` / `+0.08s`（彗星换道）/ `+0.10s`（数字相对主通道）/ `+0.18–0.30s`（同轨交接） | — | 通道延迟 |

22pt 上的可读性下限（推导出上面的数值）：
- 单通道动作 **<0.12s** 会被看成硬切，**>0.45s** 会显得图标「卡住」；单拍 0.45s 封顶。
- 数字位移 **<1.5pt** 不可读、**>2.4pt** 会出中心槽；统一取 **2.4pt**。
- 单次迁移最多 **3 个「有方向」的运动通道**（纯 opacity 通道不计），更多就是噪声。
- 不做弹簧/回弹；缓动只用 `easeIn` / `easeOut` / `easeInOut`。

### 2.3 方向语义

| 方向 | 含义 | 用在哪 |
| --- | --- | --- |
| **顺时针** | 出现 / 接管 / 新语义覆盖旧语义 | 外环扫入、色 A→色 B 新色覆盖旧环、恢复连接 |
| **逆时针** | 收回 / 让位 / 旧语义退场 | 外环收回 |
| **向上滚** | 数量增加（里程表进位，旧值向上出、新值从下方进） | 数字 +1/+n |
| **向下滚** | 数量减少（旧值向下出、新值从上方进） | 数字 −1/−n |
| **原地淡入淡出** | **无方向事件**：观测开始/中断、结果出现、字形宽度变化 | 鲸鱼、数字出现/消失、9→10、未连接符号、断连整体 |
| 水平方向 | **禁止** | —— |

断连不赋予方向：它不是「任务变了」，而是「看不到了」，任何旋转/扫出都会被误读成状态迁移。

### 2.4 多通道编排（一次 transform，而不是各动各的）

所有通道挂在同一条相对时间线上，完成窗口取最长主通道：

| 相对时间 | 通道 | 说明 |
| --- | --- | --- |
| `t = 0` | **内容交叉淡化**开始（0.24s） | 旧内容（鲸鱼/轨道/虚线环/旧数字之外的静态层）淡出、新内容淡入 |
| `t = 0` | **主通道**：外环扫入/收回/换色 或 彗星淡出 | 唯一「讲故事」的运动；画面第一眼看到的必须是它 |
| `+0.08s` | 彗星换道/入场（若与外环同拍） | 外框先动、活动弧随后换道 |
| `+0.10s` | 数字（结果）入场 | 先有状态，再有数量 |
| `+0.18s` | 外环入场（仅运行中→待办：等彗星淡出） | 同轨交接，避免两亮色同半径 |
| `+0.30s` | 彗星入场（仅待办→运行中：等外环让位） | 同上；外环收回压缩到 0.40s，交叠仅 0.10s |
| 主通道结束 | 静态帧替换 + 稳态动效接管（旋转/呼吸不重启） | 同一时刻完成，无闪帧 |

说明：若外环入场被推迟（运行中→待办），数字的延迟自动叠加为 `0.18 + 0.10 = 0.28s`，保证「数字不早于环」。
总时长 = max(内容 0.24, 外环 延迟+时长, 彗星 延迟+时长, 数字 延迟+0.23)，上限 0.60s。

内容通道的「交叉淡化」只作用于**变化的内容原子**；不变原子（同色环 / 未变数字）走公共静态层，不占时间线、也不掉亮度（§4.1）。
总时长**恒以 0.24s 内容基线兜底**：所以 M14/M15/M18 这类「只有数字变化」的迁移实测总时长是 0.24s（数字通道本身 0.18 / 0.23s）。

## 3. 迁移矩阵（M1–M18）

编号与实现一一对应；「内容」= 位图交叉淡化通道，「环」= 外环通道，「彗星」= 常驻图层通道，「数字」= 数字通道。

### 3.1 空闲 ↔ 其它状态

**M1 `idle → attention`**（0.45s）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 内容 | 鲸鱼淡出（无新内容） | 0→0.24s `easeInOut` |
| 环 | 自 12 点顺时针 `strokeEnd` 0→1，新色 | 0→0.45s `easeInOut` |
| 数字 | 原地淡入（出现不做位移） | 0.10→0.28s `easeOut` |

理由：顺时针「立环」= 注意力被接管；鲸鱼先退，环才有干净的画布，但外环 t=0 即开始生长、鲸鱼 t=0 仍 100% 不透明，所以**不存在整块空的帧**；数字最后出现 = 结果是状态的下游。

**M2 `attention → idle`**（0.45s）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 数字 | 淡出 | 0.10→0.28s `easeIn` |
| 环 | 收回：`strokeEnd` 1→0，逆时针退回 12 点 | 0→0.45s `easeInOut` |
| 内容 | 鲸鱼淡入 | 0→0.24s `easeInOut` |

理由：环逆时针退 = 待办被清空；鲸鱼作为「空场」归位，与环退场交叉淡化，无空白帧。

**M3 `idle → running`**（0.33s；内容 0.24 / 彗星 0.18 / 数字 0.10→0.33）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 内容 | 鲸鱼淡出；外轨 16% 淡入 | 0→0.24s `easeInOut` |
| 彗星 | 半径 7.9 淡入，旋转 t=0 即启动 | 0→0.18s `easeInOut` |
| 数字 | 原地淡入（运行数） | 0.10→0.28s `easeOut` |

理由：只有运行中时没有外环，彗星本身就是「运行」语义；淡入比扫入更稳（呼吸/旋转已经在表达运动）。

**M4 `running → idle`**（0.33s）：内容交叉 + 彗星淡出 + 数字淡出（0.10→0.33）；鲸鱼淡入。理由：活动结束、回到空场，不需要方向。

**M5 `idle → both`**（0.45s）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 内容 | 鲸鱼淡出；内轨 16% 淡入 @ r4.95 | 0→0.24s `easeInOut` |
| 环 | 自 12 点顺时针扫入，新色 | 0→0.45s `easeInOut` |
| 彗星 | 内半径淡入 + 旋转 | 0.08→0.26s `easeInOut` |

理由：先立外框（待办优先级）再起内弧（运行中），0.08s 错峰让两层语义可分层读出。

**M6 `both → idle`**（0.45s）：内容交叉 + 彗星淡出 + 环收回；鲸鱼最后淡入（与内容同拍）。

### 3.2 待办内部、待办 ↔ 运行

**M7 `attention(色A) → attention(色B)`**（0.45s）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 旧色环（底层） | 整圈保持（不闪空） | 静态层 |
| 新色环（上层） | 自 12 点 `strokeEnd` 0→1 覆盖旧环 | 0→0.45s `easeInOut` |
| 数字 | 值变 → M14/M15；值不变 → 不动 | 0.10s 起 |

关键点：**任一角度上同时只有一种颜色**（新色头部之前 = 新色，之后 = 旧色，接缝硬切不渐变）→ 无双环重影、无脏色、**无环闪空**。
（实现用「旧环静态层 + 新色覆盖」达到与「旧环让位 + 新色接管」完全相同的视觉结果，见 §9 决策记录。）

**M8 `attention → running`**（0.48s，同轨交接）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 内容 | 外轨淡入 | 0→0.24s |
| 环 | 收回 `strokeEnd` 1→0（压缩） | 0→0.40s `easeInOut` |
| 彗星 | 外半径淡入 + 旋转 | 0.30→0.48s `easeInOut` |
| 数字 | 值变 → 滚动（M14），出现/消失 → M18 | 0.10s 起 |

理由：外环与彗星共用 r7.9，两种亮色不能同时画 → **先收环再进彗星**；环退场压缩到 0.40s，交叠仅 0.10s。

**M9 `running → attention`**（0.60s，同轨交接；最常见：任务完成）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 彗星 | 淡出 | 0→0.18s `easeInOut` |
| 环 | 等彗星退场后扫入 | 0.18→0.60s `easeInOut`（时长压缩到 0.42s） |
| 数字 | 滚动变化 / 出现 | 0.28s 起（外环起跑后再 +0.10） |

理由：完成是用户最常看到的一次切换——先让活动弧熄灭，再让结果环立起来，数字最后落定。

**M10 `attention → both`**（同色 **0.33s** / 变色 **0.45s**）：外环颜色不变则不重播环动画（避免「状态没变却闪一下」），同色环走**公共静态层**；内容交叉（内轨淡入）；彗星 **0→0.18s** 淡入内半径（环已存在，不套用「外框先动」的 0.08s 让位）；数字（双层不放数字）0.10s 起淡出。变色时叠加 M7（总时长回到 0.45s）。
**M11 `both → attention`**（同色 **0.33s** / 变色 **0.45s**）：彗星 0→0.18s 淡出、内容交叉；环颜色不变则不动（公共静态层），变化则叠加 M7；数字 0.10s 起淡入/滚动。

### 3.3 运行 ↔ 双层（彗星半径迁移）

**M12 `running → both`**（0.53s，彗星 外径→内径）
| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 内容 | 外轨 → 内轨交叉淡化 | 0→0.24s |
| 环 | 自 12 点顺时针扫入（新色） | 0→0.45s `easeInOut` |
| 彗星 | `path` + `lineWidth` 插值 r 7.9→4.95（半径单调缩小，旋转不中断） | 0.08→0.53s `easeInOut` |
| 数字 | 淡出（双层不放数字） | 0.10s 起 |

理由：外环在外径入场，彗星必须先让到内径，否则同一半径上两色打架；半径用 `path` 插值、不用「旧层淡出新层淡入」，避免中间帧双环鬼影。

**M13 `both → running`**（0.53s）：环收回（0→0.45s）；彗星 0.08→0.53s 路径插值 r4.95→7.9（半径单调放大，旋转不中断）；数字 0.10s 起淡入/滚动。

### 3.4 数字变化（与状态迁移正交，任何状态内都适用）

**M14 同字形数增减**（数字通道 0.18s 单侧 + 0.05s 错峰；总时长 0.24s，受内容基线兜底）：旧数字垂直位移 2.4pt + opacity→0（`easeOut`）；新数字从反方向 2.4pt 移入 + opacity→1（错峰 0.05s）；增加向上、减少向下；**水平不动**。两端外环/轨道相同时走**公共静态层**，不再被双图交叉淡化压暗。
**M15 字形数变化**（9→10、99→99+）：槽宽同时改变 → 不滚动、不缩放，原地交叉淡化（0.18s，**不加 0.05s 错峰**；总时长 0.24s 同 M14 基线原因）。
**M18 数字出现/消失**（nil ↔ n）：原地淡入 / 淡出 0.18s，**不加错峰、不做位移**（槽位是空的，没有「滚动」语义）；总时长 0.24s。
**边界**：`>99` 时渲染文本恒为 `99+`，因此 100→101 等「数值变、文本不变」的推送按视觉无变化处理，**不播过渡**（`IconTransitionPlan.plan` 返回 nil）；99→100（`99`→`99+`）仍按 M15 位数变化播交叉淡化。
备注：数字出现/消失若与主通道同拍，延迟 0.10s（若外环入场被推迟则再叠加）。

### 3.5 未连接 / 恢复

**M16 任意已连接状态 `→ disconnected`**（0.24s）：当前所有原子**同拍**淡出；未连接符号（虚线环 + 短横作为一组）同拍淡入；彗星弧额外淡出 0.18s；外环不做收回扫动（它是内容的一部分直接淡掉）。
理由：断连是「观测中断」不是状态迁移，任何方向性动画都会被误读成「任务被处理了」；最快切到正确语义比优雅更重要；虚线环与短横不拆开错峰，因为它们是一个符号。

**M17 `disconnected → {idle|attention|running|both}`**（idle/running **0.24s**、attention/both **0.45s**，≤0.60s）：未连接符号随内容淡出（0.24s）；目标状态入场套用 M1/M3/M5 —— 目标有外环则 0→0.45s 顺时针扫入；目标有彗星时：与外环同拍（→both）才 0.08s 让位，无外环（→running）则 0→0.18s 直接淡入。
**注意**：连接性变化时数字不单独滚动（避免两套时间线打架），数字**烘进内容图、随内容 0.24s 淡入/淡出**，不走 0.10s 数字通道。
理由：先撤下「不可用」再呈现内容，与其它迁移同一套语言；不额外发明「重连动画」。

## 4. 分层与合成（实现契约）

### 4.1 图层栈（`IconAnimator`）

| 层 | zPosition | 内容 | 生命周期 |
| --- | --- | --- | --- |
| `button.image` | — | 过渡期间 = **22×22 透明占位图**（保持状态项宽度）；过渡结束 = 完整静态帧 | 全程存在 |
| **公共原子静态层** | 10 | 两端相同的原子（同色外环 / 未变数字 / 未变内容原子），**opacity 恒 1** | 过渡期间 |
| 旧内容位图 | 10 | 只含**变化的内容原子**（鲸鱼 / 轨道 / 未连接符号） | 过渡期间 |
| 新内容位图 | 11 | 同上，opacity 0→1 | 过渡期间 |
| 旧/新数字位图 | 20 / 21 | 只含中心数字的透明底快照 | 仅数字变化时 |
| 旧环底 / 新色扫入 / 收回环 | 30 / 31 | `CAShapeLayer`，圆心 = button bounds 中心，1pt = 1 单位（v3 起不再按按钮高度缩放） | 仅外环变化时 |
| 彗星弧 | 100 | 常驻 `CAShapeLayer`（旋转 + 呼吸） | 仅 running/both |

合成规则（v3）：**变化的原子才做交叉淡化**，不变原子走公共静态层（opacity 恒 1），
因此不会出现「相同像素各 50% 叠加 → 75% 亮度」的凹陷；入场原子从内容图排除（避免与临时层重影）、出场原子只在临时层。
全部位图 `contentsScale = 2`、`contentsGravity = .center`，与静态图同 frame/锚点，保证收尾无 1px 位移。
预算：公共层 0–1 + 内容 0–2 + 数字 0–2 + 外环 0–2 ≤ 6。

### 4.2 三种手法（只允许这三种）

| 手法 | 机制 | 用于 |
| --- | --- | --- |
| 路径扫入/收回 | `strokeEnd` 的 `CABasicAnimation`（同一 `CAShapeLayer`） | 外环 |
| 路径插值 | `path` 的 `CABasicAnimation`（两条弧结构相同 → 半径可插值） | 彗星半径迁移 |
| 位图交叉 | 临时 `CALayer.contents` = 2× CGImage 快照，animate opacity / `transform.translation.y` | 内容、数字、未连接符号 |

### 4.3 完成与兜底

- 完成时：移除全部临时层、`button.image` 换回完整静态帧、把稳态动画交回彗星层（旋转/呼吸**不重启**）。
- 完成回调用「generation token + `asyncAfter(总时长 + 0.03s)`」：过期回调直接 return；任何异常都停在该时刻的静态帧，不留在中间态。
- **CA 陷阱（已修复，务必保留）**：设置图层终值（opacity / transform / strokeEnd）时必须包在 `CATransaction.setDisableActions(true)` 里，否则 0.25s 隐式动画会按 key 顶掉显式动画（实测症状：彗星淡出从 0.18s 变成「瞬间消失」）。
- 过渡中断（新状态到来）：不打断当前动画，结束后立刻从落地状态开始下一次（§5.3）。
- 强制取消（外观切换 / 屏幕参数变化 / 按钮重建 / 动效中途关闭）：`cancelTransition()` 移除全部临时层，并清掉常驻彗星层上的过渡动画（opacity / path / lineWidth），旋转 / 呼吸保留。
- 状态项 `button` 实例被系统重建时 `attach` 返回 true → 控制器立即 `snapTo` 补静态图（不再可能长时间空白）。

### 4.4 预算

- 过渡期间临时层 ≤6（内容 2 + 数字 ≤2 + 外环 ≤2）；结束后临时层数 = 0；稳态仅 1 个彗星层（running/both）。
- 不新增 `Timer` / `CVDisplayLink` / 逐帧重绘；所有动画由 CA 提交给 WindowServer。实测稳态 CPU **0.0%**、内存 17MB。
- **重绘成本（0.4.2 实测教训）**：`NSStatusItem` 每次快照重绘都可能触发 `effectiveAppearance` KVO；若在回调里
  无条件重画 + 重设 `button.image`，macOS 27 上会形成自激循环（0.4.2 修复前常驻 85% CPU、整机 4W→12W）。
  因此：外观通知按深/浅色去重并合并到主线程下一轮；`refresh()` 里状态/外观/动效开关不变时复用缓存的
  `NSImage`，不重设相同图；toolTip / accessibilityLabel 只在变化时写。

## 5. 边界与降级

### 5.1 三档降级

| 条件 | 行为 |
| --- | --- |
| `settings.transitionAnimation == false` | 所有迁移**瞬时**切换为完整静态帧（含数字值变化） |
| Reduce Motion（`accessibilityDisplayShouldReduceMotion`） | 迁移瞬时；彗星静止静态帧。开关有监听（`accessibilityDisplayOptionsDidChange`），立即生效 |
| 低电量模式（`isLowPowerModeEnabled`） | 迁移瞬时 + 连续动画停。开关有监听（`NSProcessInfoPowerStateDidChange`），立即生效 |
| `settings.runAnimation == false` | 彗星不旋转/不呼吸，静态弧烘进静态图；**状态迁移仍按本规范播放**。⚠️ 已知例外：M8 时静态弧随内容图 t=0 淡入，与外环收回交叠 0.24s（>§6.1 同轨 0.10s）——静态模式不追求同轨节奏，见 §8 R8 |
| 未连接 | 只显示未连接符号；从已连接切过去时播放 M16，从它可以走 M17 |

### 5.2 不播场景（视为「重绘」而非「迁移」）

- App 首帧 / 状态项首次渲染。
- 深/浅外观切换（`AppleInterfaceThemeChangedNotification`）、屏幕参数变化（`didChangeScreenParameters`）、状态项按钮被系统重建：直接落静态帧并取消进行中的过渡（v3 起屏幕参数/按钮重建也真正走 snap，旧实现只在非过渡时生效）。
- 用户在设置里改「中心数字」/「显示哪些状态」：会按语义差异播放数字滚动/内容过渡（与真实状态变化一致，不做特殊处理）。
- 预览渲染 / 截图路径（`--render-previews`）：永远输出静态帧。

### 5.3 快速连续变化：single-flight + latest-wins（合并最后一个目标）

- 同一时刻只允许 1 条过渡；过渡进行中到达的新状态标脏（`hasQueuedUpdate`），**不打断当前动画**。
- 当前过渡结束 → 立刻从「刚落地的新状态」出发，用最新目标再算一次迁移计划；中间态被合并，不会排队积压。
- 最坏情况：图标视觉比真实状态晚 ≤0.60s 落地（仅当状态在 0.6s 内连续变化时）。
- 不清空队列、不闪回旧状态；每次结束都落完整静态帧，无残留图层。

## 6. 验收方法（可复现）

### 6.1 逐帧不变量

1. **包络单调**：外环扫入/收回的覆盖角在过渡内单调（允许 ≤0.5% 抖动）；彗星半径在 M12/M13 内单调。
2. **圆心恒定**：环类原子圆心 = (11,11) ±0.1pt，半径 = 7.9 / 4.95 ±0.05pt，线宽不变。
3. **数字不漂**：数字墨迹水平中心帧间漂移 ≤0.2pt；仅 M14 允许 ≤2.4pt 垂直位移；M15/M18 无位移。
4. **无双方同亮**：任一帧不得出现「新旧同时全不透明」；交叉淡化允许短暂半透明重叠，但不得双可读。
5. **目标位置不变**：环心/数字锚框/鲸鱼 bbox 中心恒定；除彗星既有 `rotation.z` 外无整体旋转/缩放/平移。
6. **时长包络**：每次迁移 0.12s ≤ 总时长 ≤ 0.60s。
7. **结尾干净**：过渡结束后 `button.image` = 完整目标静态帧，临时层数 = 0，稳态动画继续且未被重启。
8. **同轨交接**：M8/M9 中 r7.9 不得同时出现两种不透明亮色超过 0.10s（外环收回压缩 + 彗星延迟实现）。
9. **不变原子不淡化**：两端相同的外环 / 数字 / 内容原子在整个过渡内保持 100% 不透明度（公共静态层，不参与 opacity 交叉淡化）。
10. **文本相同不播**：中心数字渲染文本不变（如 100→101 都是 `99+`）时，不产生任何过渡帧（`plan` 返回 nil）。

### 6.2 禁止现象（发现即 fail）

| 现象 | 判定方法 |
| --- | --- |
| 整块跳变 / 中途硬切 | `DSH_STATUS_ANIM_SCALE=10` 慢放逐帧截图，任一帧与前后帧无关联即 fail |
| 数字鬼影 >1 帧 | 慢放中同一帧能同时读出**两个不同数值**（M14 滚动允许旧/新值半透明交叠 ≤3 帧；同一文本双影一律 fail） |
| 双环 / 双数字重影 | 外环任意角度出现两种颜色（M7 接管除外：按角度分区单色）；数字不得新旧同时全不透明 |
| 内容上下漂 / 左右漂 | 比较环心/数字质心轨迹，出现非单调位移即 fail |
| 环闪空 | 已连接→已连接迁移中，环完全不可见超过 1 帧 |
| 不变原子掉亮度 | 过渡中点稳定原子（同色外环 / 未变数字）像素亮度低于基线的 90%（旧实现双图交叉淡化会掉到 75%） |
| 同轨双亮 | M8/M9 中 r7.9 同时存在外环与彗星亮色超过 2 帧 |
| 彗星跳位/重启 | 过渡中 `rotation.z` 时间归零导致弧头瞬移 |
| 位数变化时抖动 | M15 出现水平位移或宽度压缩 |
| 菜单栏重建残影 | 切换桌面/屏幕参数后截图有临时层残留 |
| CPU 回归 | 过渡期间 1s 均值 >3%，或稳态非 0.0%（外观通知去重 / 静态图缓存须生效，0.4.2 起） |

## 9. 决策记录（原设计评审稿的两处待确认项）

1. **颜色变化 M7 采用「新色顺时针覆盖旧环」**（旧环始终整圈作底，不闪空、无断口），而不是旧方案「旧环先消失再扫一圈」的重画感。
   实现层用「旧环静态层 + 新色 `strokeEnd` 0→1」得到完全相同的按角度分区单色效果；**已采纳**。
2. **断连 M16 采用「无方向同拍淡出」**（0.24s，比原稿 0.34s 更快）：语义是「看不到了」而不是「任务被处理了」；
   实测慢放下 0.24s 已足够可读，且和其它内容交叉淡化共用一条时间线。**已采纳**。
