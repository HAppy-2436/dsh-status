# 菜单栏图标「全状态切换动效」规范

> 状态：v1 设计评审稿（2026-11-07）· 适用 `MenuBarIconRenderer` / `CometAnimator` / `StatusItemController`
> 读者：实现者、设计评审者。本文是**动效契约**：参数照抄即可实现；本文未列出的动效一律不做。
> 前置：[app-design.md §2](app-design.md)（图标 v5 语义与几何）、[icon-suggestions.md](icon-suggestions.md)（P1-6/P1-7）、
> [research/macos-ui-conventions.md](research/macos-ui-conventions.md)（HIG 动效原则）。
> **本文不改图标几何、配色语义与信息结构，只定义过渡。**

## 0. 结论先行

1. **本轮把动效从「只有外环变化有过渡」扩展到全部语义迁移**，共 17 条迁移（§3），覆盖空闲/待办/运行/双层/未连接之间的所有有意义切换。
2. **保留已验收语言**：外环 0.45s `easeInOut` 自 12 点顺时针扫入（颜色变化升级为 M7「新色接管」，见 §9 待确认）；彗星旋转/呼吸参数不动；`button.image` 继续做系统重绘的静态兜底。
3. **所有过渡都基于同一条时间线**：主拍 0.45s → 次通道错峰 +0.06~0.10s → 数字（结果）最后 +0.18~0.22s；单次迁移总时长硬上限 0.60s。
4. **方向即语义**：顺时针 = 出现/接管，逆时针 = 收回/让位；数字只做垂直「里程表」滚动（2.0pt），**永远不做水平位移**。
5. **内容的目标位置绝不变化**：不做布局/尺寸/窗口动画，不整体位移、不缩放；只有数字字形在固定中心槽内滚动。
6. **实现只用 Core Animation 图层 + 位图交叉淡化**：不逐帧重绘、不新增 Timer/DisplayLink，过渡临时层 ≤4 个，结束后清零，稳态 CPU 保持 0.0%。
7. **降级三档不变**：`transitionAnimation` 关 / Reduce Motion / 低电量 → 过渡瞬时；`runAnimation` 关 → 彗星静止但状态过渡仍播。

## 1. 状态空间与视觉原子

### 1.1 状态枚举

连接态只有"已连接 / 未连接"两档；已连接下由「待办（需要介入）」与「运行中」两个维度组合：

| 状态 | 代号 | 鲸鱼 | 外环 | 内轨 | 彗星弧 | 中心数字 | 未连接符号 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 未连接 | `disconnected` | — | — | — | — | — | 虚线环 + 短横 |
| 完全空闲 | `idle` | ✓ | — | — | — | — | — |
| 只有待办 | `attention` | — | ✓（红/黄/绿） | — | — | ✓（按语义） | — |
| 只有运行中 | `running` | — | — | ✓ @ r7.9 | ✓ @ r7.9 | ✓（运行数） | — |
| 运行中 + 待办 | `both` | — | ✓（红/黄/绿） | ✓ @ r4.95 | ✓ @ r4.95 | —（双层不放数字） | — |

约束（不变）：外环单色、颜色取最高优先级 **红(已停止) > 黄(待回答) > 绿(已完成)**；双层时中心不放数字；
`connected == false` 时 `statuses` 视为空，但视觉以未连接符号为准。

### 1.2 视觉原子与动画介质

| 原子 | 内容 | 过渡介质（本规范指定） | 备注 |
| --- | --- | --- | --- |
| 鲸鱼 | 18.8pt 宽 deepseek glyph | 位图快照 opacity 交叉 | 只出现在 idle 与出场层 |
| 外环 | r7.9 / 线宽 2.1 / 整圈单色 | `CAShapeLayer` 的 `strokeEnd` / `strokeStart` / `strokeColor` | 圆心、半径、线宽过渡中恒定 |
| 内轨 | 淡色整环（16%），半径随层级 7.9 或 4.95 | `CAShapeLayer` 路径 + opacity | 半径做路径插值，不换层重画 |
| 彗星弧 | 亮弧，半径 7.9 或 4.95 | 既有 `cometLayer`：`strokeEnd` 扫入/退出、`path` 半径插值、`transform.rotation.z`、既有呼吸 | **过渡不重建、不重启旋转** |
| 中心数字 | 1/2/3 字形，圆体 Bold，面积质心居中 | 位图快照 opacity；值变化用 `transform.translation.y` ≤2.0pt | 锚点固定 (11,11)，水平不位移 |
| 未连接符号 | 虚线环 r7.9/w1.6/dash 2.2,3.2 + 短横 6×1.4 | 整图位图 opacity | 虚线环与短横**同一组**，不拆开错峰 |

### 1.3 数字语义（不变，仅动画需要区分）

| 设置「中心数字」 | 显示值 | 0 的约定 |
| --- | --- | --- |
| 全部任务（默认） | 非空闲任务总数 | 0 = **不显示数字**，绝不渲染 "0" |
| 需要介入 | 待回答+已停止+已完成；为 0 时回落为运行数 | 同上 |
| 与环色一致 | 环色对应状态计数；无待办时回落为运行数 | 同上 |
| 不显示 | 永远 nil | — |

- 数字格式：`count > 99` 显示 `99+`。
- 槽位：中心 (11,11)，可用约 9×11pt；字号 10.4 / 9.0 / 7.6pt 随字形数递减（不变）。
- 过渡只改变「显示方式」，不改变上述取值规则。

## 2. 统一动效语言

### 2.1 三条不可违反的原则

1. **不位移**：图标内容（环心、数字锚框、鲸鱼 bbox 中心）在过渡中的目标位置恒定；禁止整体平移/缩放/布局动画/窗口动画。
   —— 直接回应用户上轮对「内容一会下一会上」的批评：两段式位移在本规范中一律违规。
2. **单拍**：一次状态迁移 = 一拍；所有通道共用同一时间线（见 §2.4），不各动各的。
3. **语义→运动隐喻**：每个动画都能用一句话解释「它在表达什么」（见 §2.3），解释不了就不做。

### 2.2 时长层级

| 层级 | 时长 | 缓动 | 用途 |
| --- | --- | --- | --- |
| 主拍 | **0.45s**（让位变体 0.26–0.30s） | `easeInOut` | 外环扫入/收回/颜色接管、彗星进场/退场 |
| 次拍 | **0.18–0.24s** | 入场 `easeOut`，出场 `easeIn` | 鲸鱼、内轨、未连接符号、数字的淡入淡出 |
| 微拍 | **0.12–0.16s** | `easeIn` | 旧数字、断连时的整体淡出 |
| 数字滚动 | **0.14s 出 + 0.18s 入，错峰 0.03s** | `easeIn` / `easeOut` | 同字形数增减 |
| 复合上限 | **≤0.60s** | — | 一次迁移总时长硬上限 |
| 错峰阶梯 | 0 / +0.06~0.10 / +0.18~0.22s | — | 主通道 / 次通道 / 数字 |
| 合并窗口 | 状态 0.15s；数字 0.12s；连接态 1.0s | — | 连续变化只保留最新目标（§5.3） |

22pt 上的可读性下限（推导出上面的数值）：
- 单通道动作 **<0.12s** 会被看成硬切，**>0.45s** 会显得图标"卡住"；因此单拍 0.45s 封顶。
- 位移 **<1.5pt** 不可读、**>2.2pt** 会出中心槽；数字滚动统一取 **2.0pt**。
- 单次迁移最多 **3 个"有方向"的运动通道**（纯 opacity 通道不计），更多就是噪声。
- 不做弹簧/回弹（22pt 上回弹 = 抖动）；缓动只用 `easeIn` / `easeOut` / `easeInOut`。

### 2.3 方向语义

| 方向 | 含义 | 用在哪 |
| --- | --- | --- |
| **顺时针** | 出现 / 接管 / 新语义覆盖旧语义 | 外环扫入、色 A→色 B 新色接管、彗星进场、恢复连接 |
| **逆时针** | 收回 / 让位 / 旧语义退场 | 外环收回、旧色让位、彗星退出 |
| **向上滚** | 数量增加（里程表进位） | 数字 +1/+n（新值从下方进） |
| **向下滚** | 数量减少 | 数字 −1/−n |
| **原地淡入淡出** | **无方向事件**：观测开始/中断、结果出现 | 鲸鱼、数字出现/消失、未连接符号、断连整体 |
| 水平方向 | **禁止** | —— |

断连不赋予方向：它不是"任务变了"，而是"看不到了"，任何旋转/扫出都会被误读成状态迁移。

### 2.4 多通道编排（一次 transform，而不是各动各的）

所有通道挂在同一条相对时间线上，完成窗口取最长主通道：

| 相对时间 | 通道 | 说明 |
| --- | --- | --- |
| `t = 0` | **主通道**：外环或彗星的方向性动作 | 唯一"讲故事"的运动；画面第一眼看到的必须是它 |
| `0 ~ 0.16s` | 出场原子（旧数字/鲸鱼/旧符号）同拍淡出 | 让位方先走，不等入场方 |
| `+0.06 ~ +0.10s` | 次通道：内轨、另一层的彗星 | 比主通道晚 ≤0.10s，避免"整块一起亮" |
| `+0.18 ~ +0.22s` | 数字（结果） | 数字最后出现：先有状态，再有数量 |
| 主通道结束 | 静态帧替换 + 稳态动效接管（旋转/呼吸） | 同一事务内完成，无闪帧 |

缓动：主拍统一 `CAMediaTimingFunction(name: .easeInEaseOut)`（与已验收的外环过渡一致）；次拍入场 `.easeOut`、出场 `.easeIn`；数字 `.easeOut`。

## 3. 迁移矩阵

编号 M1–M17。每行 = 该迁移里一个原子/通道的动作；"底图"指过渡期间 `button.image` 显示的静态目标帧（§4.1）。

### 3.1 空闲 ↔ 其它状态

**M1 `idle → attention`**（0.45s）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 鲸鱼 | 出场：opacity 1→0 | 0→0.18s `easeIn` |
| 外环 | 入场：自 12 点顺时针 `strokeEnd` 0→1，新色 | 0→0.45s `easeInOut` |
| 数字 | 入场：opacity 0→1，无位移无缩放 | 0.20→0.38s `easeOut` |

底图 = 目标静态帧去掉外环与数字。理由：顺时针"立环"= 注意力被接管；鲸鱼先退，环才有干净的画布，
但外环 t=0 即开始生长、鲸鱼 t=0 仍 100% 不透明，所以**不存在整块空的帧**；数字最后出现 = 结果是状态的下游。

**M2 `attention → idle`**（0.45s）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 数字 | 出场 opacity→0 | 0→0.12s `easeIn` |
| 外环 | 收回：`strokeEnd` 1→0，逆时针退回 12 点 | 0→0.45s `easeInOut` |
| 鲸鱼 | 入场 opacity 0→1 | 0.22→0.44s `easeOut` |

理由：环逆时针退 = 待办被清空；鲸鱼作为"空场"最后归位，数字先走避免与鲸鱼叠。

**M3 `idle → running`**（0.45s）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 鲸鱼 | 出场 opacity→0 | 0→0.16s `easeIn` |
| 轨道 | 入场 opacity 0→1（16%） | 0.04→0.24s `easeOut` |
| 彗星 | 入场：半径 7.9，`strokeEnd` 0→0.26 顺时针；旋转 t=0 即启动 | 0→0.40s `easeInOut`；0.40s 起接既有呼吸（0.26⇄0.58、1.7s） |
| 数字 | 入场 opacity 0→1 | 0.20→0.38s `easeOut` |

理由：只有运行中时没有外环，彗星本身就是"运行"语义；扫入终点取呼吸下沿 0.26 而非常用静态 0.35，
**避免交接瞬间弧长跳变**；旋转与扫入同拍启动，读作"它已经在转，只是刚刚被看见"。

**M4 `running → idle`**（0.44s）：数字 0→0.12s、轨道 0.06→0.20s 淡出（均 `easeIn`）；
彗星 `strokeEnd` 0.26→0 逆时针退出（0→0.30s `easeIn`，旋转到弧消失再停）；鲸鱼 0.24→0.44s `easeOut` 淡入。

**M5 `idle → both`**（0.50s）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 鲸鱼 | 出场 opacity→0 | 0→0.16s `easeIn` |
| 外环 | 入场：自 12 点顺时针 `strokeEnd` 0→1，新色 | 0→0.45s `easeInOut` |
| 内轨 | 入场 opacity 0→1 @ r4.95 | 0.08→0.26s `easeOut` |
| 内层彗星 | 入场：`strokeEnd` 0→0.26 顺时针 + 旋转 | 0.08→0.44s `easeInOut` |

理由：先立外框（待办优先级）再起内弧（运行中），0.08s 错峰让两层语义可分层读出、且方向通道不同时起跑。

**M6 `both → idle`**（0.50s）：内层彗星 `strokeEnd`→0 逆时针 0→0.26s 退出、内轨 0.02→0.18s 淡出；
外环 `strokeEnd` 1→0 逆时针 0→0.45s 收回；鲸鱼 0.24→0.50s `easeOut` 最后淡入（空场归位）。

### 3.2 待办内部、待办 ↔ 运行

**M7 `attention(色A) → attention(色B)`**（0.45s，已验收语言的升级）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 旧色环（底层） | 整圈**让位**：`strokeStart` 0→1，尾部随新色头部顺时针推进；opacity 保持 1 | 0→0.45s `easeInOut` |
| 新色环（上层） | **接管**：自 12 点 `strokeEnd` 0→1 | 0→0.45s `easeInOut` |
| 数字 | 值变 → M14/M15；值不变 → 不动 | 0.18s 起 |

关键点：**任一角度上同时只有一种颜色**（新色头部之前 = 新色，之后 = 旧色，接缝硬切不渐变）→ 无双环重影、
无脏色、**无环闪空**；结束时旧层移除 + 底图替换为完整新帧（同像素）。这保留了原来 0.45s 顺时针扫入 + 颜色变化的观感，
但把"旧环先消失再扫"改成了"新色顺时针接管旧环"。

**M8 `attention → running`**（0.58s，同轨交接）

| 通道 | 动作 | 参数 |
| --- | --- | --- |
| 数字 | 淡出（若目标仍显示数字则改为更新，见 M14/M15） | 0→0.12s `easeIn` |
| 外环 | 收回：`strokeEnd` 1→0，逆时针（让位变体） | 0→0.26s `easeInOut` |
| 轨道 | 入场 opacity 0→1 @ r7.9 | 0.18→0.34s `easeOut` |
| 彗星 | 入场：`strokeEnd` 0→0.26 顺时针 + 旋转 | 0.28→0.58s `easeInOut` |
| 数字（新值） | 入场 0.32→0.50s `easeOut` | —— |

理由：外环与彗星共用 r7.9，两种亮色不能同时画 → **先退后进**，中间由淡轨道过渡；环退场压缩到 0.26s
（主拍让位变体）正好在彗星进场前让开，全程无同轨双色。

**M9 `running → attention`**（0.56s）：彗星 `strokeEnd`→0 退出（0→0.24s `easeIn`，旋转到消失）、轨道 0.02→0.16s 淡出；
外环 0.16→0.56s 顺时针扫入（新色）；数字 0.34s 起更新（值变 → M14/M15），不晚于 0.44s 到位。

**M10 `attention → both`**（0.46s；外环颜色同时变化则叠加 M7）：数字 0→0.12s 淡出（双层不放数字）；
内轨 0.06→0.24s `easeOut` 淡入 @ r4.95；内层彗星 0.10→0.46s `easeInOut` `strokeEnd` 0→0.26 顺时针扫入 + 旋转。
理由：外环语义不变就**不重播环动画**（避免"状态没变却闪一下"）；数字必须在内层彗星靠近中心前退完
（内环内缘 r4.25 与数字外缘 ≈r3.5 只差 0.75pt）。

**M11 `both → attention`**（0.45s）：内层彗星 0→0.24s `easeIn` 退出（`strokeEnd`→0）、内轨 0.02→0.16s 淡出；
数字 0.26→0.44s `easeOut` 原地淡入；外环颜色不变则不动，变化则叠加 M7。

### 3.3 运行 ↔ 双层（彗星半径迁移）

**M12 `running → both`**（0.57s，彗星 外径→内径）：数字 0→0.12s `easeIn` 淡出；
彗星与轨道 0.04→0.34s `easeInOut` 路径插值 r 7.9→4.95（**半径单调缩小**，旋转不中断）；
外环 0.12→0.57s `easeInOut` 自 12 点顺时针扫入（新色）。
理由：外环在外径入场，彗星必须先让到内径，否则同一半径上两色打架；半径用 `path` 插值、
不用"旧层淡出新层淡入"，避免中间帧出现双环鬼影。

**M13 `both → running`**（0.50s）：外环 0→0.28s `easeInOut` 收回（`strokeEnd` 1→0，让位变体）；
彗星与轨道 0.16→0.46s 路径插值 r 4.95→7.9（半径单调放大）；数字 0.32→0.50s `easeOut` 淡入。

### 3.4 数字变化（与状态迁移正交，任何状态内都适用）

**M14 同字形数增减**（如 1→2、8→9、12→13；总计 0.21s）：旧数字上/下移 2.0pt + opacity→0（0→0.14s `easeIn`，
增加向上、减少向下）；新数字从反向 2.0pt 位置移入 + opacity→1（0.03→0.21s `easeOut`）；
**水平不动**，每个字形按面积质心在自己的最终位置居中。

**M15 字形数变化**（9→10、99→99+；总计 0.18s）：旧数字原地 opacity→0（0→0.12s `easeIn`）、
新数字原地 opacity→1（0.02→0.18s `easeOut`）；不滚动、不缩放、不做宽度压缩/水平滑动。
理由：字形数变化时槽宽同时改变，滚动 + 宽度变化会在 22pt 上必抖；原地交叉最稳。
`0→1` 与 `N→0` 按「数字出现/消失」处理：0.18s `easeOut` / 0.12s `easeIn`，不滚动。

### 3.5 未连接 / 恢复

**M16 任意已连接状态 `→ disconnected`**（0.34s）：当前所有原子**同拍** opacity 1→0（0→0.16s `easeIn`，不错峰、
无方向）；未连接符号（虚线环 + 短横作为一组）0.14→0.34s `easeOut` 淡入。若断连发生在过渡中，取消当前过渡、
从当前可见帧直接走本动画（§5.3）。理由：断连是"观测中断"不是状态迁移，任何方向性动画都会被误读成"任务被处理了"；
最快切到正确语义比优雅更重要；虚线环与短横不拆开错峰，因为它们是一个符号。

**M17 `disconnected → {idle|attention|running|both}`**（≤0.60s）：未连接符号 0→0.12s `easeIn` 淡出；
目标状态入场套用 M1/M3/M5 对应规范，整体延迟 0.06s 启动；目标含数字时数字 0.26→0.44s `easeOut` 随后出现。
理由：先撤下"不可用"再呈现内容，0.06s 交接不断档；不额外发明"重连动画"，避免同一语义两套语言。

## 4. 分层与合成（实现契约）

### 4.1 图层栈

| 层 | 内容 | 生命周期 |
| --- | --- | --- |
| L0 `button.image` | **过渡底图** = 目标静态帧去掉「入场原子」；始终非空、始终同心 | 全程存在，菜单栏重建时系统直接可用 |
| L1…L4 临时层 | 出场位图（鲸鱼/旧数字/未连接符号）、形状层（外环/内轨/彗星）、入场位图（数字） | 过渡期间 ≤4 个，结束即移除 |
| 既有 cometLayer | 稳态旋转/呼吸，过渡期间可被复用做半径插值与扫入 | 常驻（仅 running/both） |

合成规则：**入场原子从底图排除**（避免和临时层重影）、**出场原子只放临时层**（底图里已没有）、
**不变原子留在底图**（不参与动画）。这是现有外环过渡已验证的做法，本轮推广到全部原子。

### 4.2 三种手法（只允许这三种）

| 手法 | 机制 | 用于 |
| --- | --- | --- |
| 路径扫入/收回 | `strokeEnd` / `strokeStart` 的 CABasicAnimation（同一 `CAShapeLayer`，不换 path） | 外环、彗星 |
| 路径插值 | `path` 的 CABasicAnimation（两条弧结构相同 → 半径可插值） | 内轨、彗星半径迁移 |
| 位图交叉 | 临时 `CALayer.contents` = 2× CGImage 快照，animate opacity / `transform.translation.y` | 鲸鱼、数字、未连接符号 |

### 4.3 完成与兜底

- 完成时在**同一个 `CATransaction`** 内：`button.image = 完整目标静态图` + 移除临时层 + 交回稳态动画（彗星旋转/呼吸不重启）。
- 静态图与临时层必须同 `frame` / 同 `anchorPoint` / 同 `contentsScale=2`；圆心取整 `round(bounds.midX/midY)`，
  顺带修掉已记录的 0.5pt 支点偏差。
- 过渡中断/回调异常：保留现有 0.75s 兜底定时器思路，直接切完整静态帧，不留在中间态。

### 4.4 前置实现接口（唯一新增）

renderer 现有 `includeRing` 之外，需要能**按原子渲染**（`includeRing / includeTrack / includeComet / includeNumber`，
或等价 `renderAtoms(model, atoms:)`），用于生成底图与位图快照。这是合成前提，不改变视觉。
若暂不提供：数字/内轨的「错峰入场」降级为随主拍同拍交叉淡化（视觉损失小），M14/M15 的数字值动画仍需中心单原子渲染；
若连这个也不具备，数字变化降级为 0.18s 原地交叉淡化。

### 4.5 预算

- 过渡期间临时层 ≤4；过渡结束后临时层数 = 0；稳态仅 1 个彗星层（running/both）。
- 不新增 `Timer` / `CVDisplayLink` / `NSImage` 逐帧重绘；所有动画由 CA 提交给 WindowServer。
- 过渡期间瞬时 CPU 允许短时上升，但 1s 采样应 ≤3%，稳定后 0.0%（沿用既有验收口径）。

## 5. 边界与降级

### 5.1 三档降级

| 条件 | 行为 |
| --- | --- |
| `settings.transitionAnimation == false` | 所有迁移**瞬时**切换为完整静态帧（含数字值变化） |
| Reduce Motion（`accessibilityDisplayShouldReduceMotion`） | 迁移瞬时；彗星静止静态帧（沿用现状） |
| 低电量模式（`isLowPowerModeEnabled`） | 迁移瞬时 + 连续动画停（沿用现状） |
| `settings.runAnimation == false` | 彗星不旋转/不呼吸，显示静态弧；**状态迁移仍按本规范播放**（环/数字/内轨） |
| 未连接 | 只显示未连接符号，不播任何入场动画（恢复连接时见 M17） |

### 5.2 不播场景（视为"重绘"而非"迁移"）

- App 首帧 / 状态项首次渲染（`hasRenderedOnce` 之前）。
- 深/浅外观切换（`AppleInterfaceThemeChangedNotification`）、屏幕参数变化（`didChangeScreenParametersNotification`）。
- 菜单栏重建、状态项迁移到另一块屏幕：立即切完整静态帧，临时层清理。
- 用户在设置里改「中心数字」/「显示哪些状态」：瞬时重绘，不播数字滚动。
- 预览渲染 / 截图路径（`--render-previews`）：永远输出静态帧。

判定方式：动效只在「同一模型上下文中 `iconModel` 的语义字段变化」时触发；
外观、几何、设置项变化**不进**过渡触发条件（现有 `imageSignature` 需把 `dark` 拆出动画判定）。

### 5.3 快速连续变化：single-flight，latest-wins

- **不排队**：同一时刻只允许 1 条过渡；新迁移到来 → 取消旧过渡，从「最近稳定帧」直接到「最新目标」。
- **不闪回**：0.15s 内 A→B→A 的抖动，最终只看到 A 的静态帧，B 一帧都不播；连接态用 1.0s 防抖窗
  （桥重启/心跳抖动不播断连）。
- **数字高频变化**：0.12s 内连续新值合并为一次；动画进行中被新值取代 → 取消，以最终值交叉淡化 0.12s。
- **从当前可见帧出发**：取消过渡时不做"倒放"，直接把 `button.image` 设为最新目标底图再开新过渡；
  不允许出现"先回到旧状态再过渡"的闪回。
- 连续快速切换 20 次后，最终视觉必须是**最终状态的完整静态帧**，无残留临时层、无残影。

## 6. 可量化验收指标

### 6.1 逐帧不变量（每条迁移都必须满足）

1. **包络单调**：外环扫入/收回的覆盖角在过渡内单调（帧间不回头，允许 ≤0.5% 抖动）；彗星半径在 M12/M13 内单调。
2. **圆心恒定**：所有环类原子的圆心 = (11,11) ±0.1pt，半径 = 7.9 / 4.95 ±0.05pt，线宽不变。
3. **无水平漂移**：数字墨迹水平中心在过渡前后差 ≤0.2pt，帧间水平位移 ≤0.1pt/帧。
4. **垂直滚动受限**：仅 M14 允许数字垂直位移，幅度 ≤2.0pt 且不出中心槽；帧间 ≤0.6pt。
5. **无双方同亮**：任意原子在任意一帧不得出现「新旧同时全不透明」（防双数字/双环鬼影）；交叉淡化允许短暂半透明重叠，但不得双可读。
6. **目标位置不变**：环心/数字锚框/鲸鱼 bbox 中心在过渡中目标值恒定；除彗星既有 `rotation.z` 外无整体旋转/缩放/平移。
7. **时长包络**：每次迁移 0.12s ≤ 总时长 ≤ 0.60s；任意 100ms 窗口内「有方向」通道 ≤3。
8. **结尾干净**：过渡结束后 `button.image` = 完整目标静态帧，临时层数 = 0，稳态动画继续且未被重启。

### 6.2 禁止现象（发现即 fail）

| 现象 | 判定方法 |
| --- | --- |
| 整块跳变 / 中途硬切 | `DSH_STATUS_ANIM_SCALE=10` 慢放逐帧截图，任一帧与前后帧无关联即 fail |
| 数字鬼影 >1 帧 | 慢放中同一帧能同时读出旧值和新值（>1 帧） |
| 双环 / 双数字重影 | 外环任意角度出现两种颜色（M7 接管除外：那是**按角度分区**的单色，不是重叠双色） |
| 内容上下漂 / 左右漂 | 比较环心/数字质心轨迹，出现非单调位移即 fail |
| 环闪空 | 已连接→已连接迁移中，环完全不可见超过 1 帧 |
| 同轨双亮 | M8/M9 中 r7.9 同时存在外环与彗星亮色超过 2 帧 |
| 彗星跳位/重启 | 过渡中 `rotation.z` 时间归零导致弧头瞬移 |
| 位数变化时抖动 | M15 出现水平位移或宽度压缩 |
| 菜单栏重建残影 | 切换桌面/屏幕参数后截图有临时层残留 |
| CPU 回归 | 过渡期间 1s 均值 >3%，或稳态非 0.0% |

### 6.3 验收方法

- 逐帧：`DSH_STATUS_ANIM_SCALE=10` 放慢（现有调试开关）+ 2× 截图逐帧看；每类迁移至少 1 条录屏。
- 矩阵：用 mock 桥依次触发 17 条迁移，深/浅外观各一遍。
- 降级：`transitionAnimation` 关、`runAnimation` 关、Reduce Motion、低电量各跑一遍，确认瞬时/静止且最终帧正确。
- 手感：连续观察 10 分钟不觉得烦；快速切 20 次无残留；`top` 采样稳态 0.0%。

## 7. 保留 / 不改 / 不做

### 7.1 保留（已验收，不推翻）

- 外环 **0.45s `easeInOut` 自 12 点顺时针扫入**（本轮把「旧色单层渐变」升级为 M7 双色接管，待用户确认）。
- 彗星旋转：6s 转 3 圈（平均 2s/圈）、±32% 正弦速度调制、首尾整数圈；呼吸 `strokeEnd` 0.26⇄0.58、1.7s 单程。
- 静态层走 `button.image` 的系统兜底策略、`NSApp.effectiveAppearance` 判定外观。
- 设置项语义、Reduce Motion / 低电量降级路径。

### 7.2 不改清单

22pt 画布与 (11,11) 圆心；外环 r7.9/w2.1；内环 r4.95/w1.4；未连接 r7.9/w1.6/dash 2.2,3.2/短横 6×1.4；
statusRGB 四色与优先级（红>黄>绿）；数字字号/格式/语义；信息结构；菜单栏可点击区域与高亮。

### 7.3 明确不做

布局动画、窗口/尺寸动画、图标整体缩放、逐帧重绘、多段式位移（"一会下一会上"）、弹簧回弹、
为动效新增常驻定时器、改变几何或配色的"顺带美化"。

## 8. 实现风险与降级方案（设计评审结论）

| # | 风险 | 影响 | 降级方案 |
| --- | --- | --- | --- |
| R1 | **同轨交接**（M8/M9）外环与彗星都在 r7.9，串行后仍有 0.02s 级视觉交叠风险 | 中：22pt 上两亮色相切显脏 | 环退场改为 0.20s 原地淡出（无方向）替代逆时针扫回，总时长 0.50s；语义损失可接受 |
| R2 | **按原子渲染接口不存在**（renderer 目前只有 `includeRing`） | 中：数字/内轨错峰入场做不了 | 降级为随主拍同拍交叉；数字值变化（M14/M15）优先级更高，先保证 |
| R3 | **双图层颜色接管**（M7）的硬接缝在 1× 屏可能有 1px 抗锯齿色边 | 低：只在扫过瞬间可见 | 两层同 path/线宽/圆头端点让新层覆盖接缝；仍可见则回退「旧环淡出 + 新环扫入」（代价：环闪空 ~0.15s） |
| R4 | **临时层位图与静态图 1px 像素差** → 收尾瞬间闪一下 | 中：反复出现会像抖动 | 同事务替换 + 必要时 60ms 交叉淡化掩盖；2× 渲染与整圆心是其前提 |
| R5 | **彗星签名重启**：状态列表/运行数变化会重启动画（现有 signature 含 statuses/runningCount） | 高：both 状态多一个运行会话会看到彗星跳位 | 彗星签名只保留「影响视觉的字段」：半径档位、颜色、dark、animate；数量变化不重启 |
| R6 | 断连/恢复高频抖动（桥重启、网络闪断） | 中：图标闪烁 | 1.0s 连接防抖 + single-flight；抖动窗口内只保留最终态，不播中间过程 |

## 9. 待用户确认的手感点

1. **颜色变化 M7 改为「新色顺时针接管旧环」**（不再先消失再扫一圈）：不闪空、无断口，但少了现在这种"重画"感。
   若用户更喜欢现有观感，可退回已验收行为。
2. **断连 M16 采用「无方向同拍淡出」**（0.34s）而非旋转/扫出：更准确表达"看不到了"，但比扫出"朴素"。
   以及断连总时长 0.34s 是否够快（可加长到 0.40s）。
